# Submeter Bill Calculator

ভাড়াটিয়ার সাবমিটারের ইউনিট আর মিটারের মাসিক খরচ থেকে ভাড়াটিয়ার বিদ্যুৎ বিল বের করার টুল।

Bill = total charged on the DPDC panel for the period x (tenant units / main meter units).
An optional "half of fixed charge" mode is available.

Run locally: `npm start`, then open http://localhost:3000
